# Third-party notices

## World map geometry

Patch uses the world country path data from [`@svg-maps/world`](https://github.com/VictorCazanave/svg-maps/tree/master/packages/world), created by Victor Cazanave and licensed under the [Creative Commons Attribution 4.0 International license](https://creativecommons.org/licenses/by/4.0/).

Patch does not change the source geometry. It renders the paths with application-specific colors, selection states, labels, and visited-country interactions.
