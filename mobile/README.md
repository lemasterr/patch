# Patch mobile client

`mobile/` is the Expo SDK 57 client for iOS and Android. It uses Expo Router,
React Native, Supabase Auth/Realtime, React Query, SecureStore sessions, and a
durable SQLite-backed offline queue.

## Product boundaries

- Patch does not collect device location for Patch creation.
- Authentication callbacks use `patch://auth/callback`.
- Public Supabase URL and publishable key are build-time public values; no
  service-role credential belongs in the app.
- Creation, retries, account deletion, and background processing are handled
  by authenticated or service-only Edge Functions.
- Offline persistence is intentionally limited to account-scoped creation
  drafts, durable queued actions, completed queued-creation results, and the
  allow-listed Discover cache. It is cleared when that account signs out.

## Commands

Run these from `mobile/`:

```bash
npm ci
npm run typecheck
npm run lint
npm test
npm run doctor
npm run export:ios
npm run export:android
```

For local backend and simulator launch commands, use the repository root as
documented in [the root README](../README.md).

## Native generation and release builds

`ios/` and `android/` are generated by Expo prebuild and intentionally ignored.
Regenerate them after a reviewed native dependency or `app.config.ts` change:

```bash
npm run prebuild
```

`eas.json` defines development, internal preview, and production profiles. A
production build must be linked to the approved EAS project, use hosted public
Supabase values, exclude the development client, and be signed through the
approved Apple/Android workflow. See [the release checklist](../RELEASE_CHECKLIST.md).
